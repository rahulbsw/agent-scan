# Maintainers

Current maintainer:

- Rahul Singh Bais (`@rahulbsw`)

Maintainers are responsible for triage, review, release decisions, security
advisory coordination, and preserving the community project identity.

## Adding Maintainers

Maintainers can nominate contributors who consistently provide high-quality
reviews, rules, docs, tests, or security research. Adding a maintainer requires
agreement from the current maintainer group.

## Emeritus Maintainers

Maintainers who step back can be listed here later for attribution.
