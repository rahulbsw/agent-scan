# Code Of Conduct

Open Agent Scan adopts the Contributor Covenant approach: clear expectations,
respectful collaboration, and maintainers empowered to protect the project.

## Expected Behavior

- Be respectful and constructive.
- Focus on evidence, reproducibility, and user impact.
- Welcome contributors with different backgrounds and security specialties.
- Accept that scanner rules require precision, tests, and false-positive review.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private vulnerability details before coordinated disclosure.
- Submitting real secrets, customer data, or harmful callbacks in fixtures.
- Repeatedly pushing speculative detections as high-confidence findings without
  evidence.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or
contributions that violate this code. Repeated or severe violations can result
in temporary or permanent exclusion from project spaces.

This document is based on the Contributor Covenant model:
https://www.contributor-covenant.org/
