# Attribution

Open Agent Scan is an independent downstream derivative of
[`snyk/agent-scan`](https://github.com/snyk/agent-scan).

The upstream project is licensed under Apache-2.0. This downstream keeps the
same license, preserves copyright notices, and retains upstream attribution.

Open Agent Scan is not affiliated with, sponsored by, or endorsed by Snyk or
Invariant Labs. The names Snyk and Invariant Labs belong to their respective
owners and are used only to describe the origin of the upstream work.

## Downstream Changes

This downstream changes the public project identity, package name, release
assets, contribution model, governance docs, and local rule framework to support
an open community project.

## Upstream Contribution Policy

As of the upstream contribution guide reviewed for this rebrand,
`snyk/agent-scan` no longer accepts external contributions. Open Agent Scan is
therefore maintained as a community downstream rather than a routine upstream PR
branch.
