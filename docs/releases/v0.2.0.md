# Open Agent Scan v0.2.0

Open Agent Scan is an independent downstream derivative of
[snyk/agent-scan](https://github.com/snyk/agent-scan), licensed under Apache-2.0.
It is not affiliated with, sponsored by, or endorsed by Snyk or Invariant Labs.
Upstream history and attribution are preserved.

## Changes

- Integrates upstream through `ebf2d6fcfa67194d49abf4e28d68bc7ca41dd0d0`
  (the upstream v0.7.0 development line).
- Expands agent, workspace, plugin, and VS Code extension discovery, including
  GitHub Copilot project configurations.
- Adds newer hook retries, atomic configuration writes, guard-owned backups,
  machine-serial metadata, and explicit managed-install checks. Keeps the fork's
  hook names and install-time CLI version substitution.
- Improves async remote-analysis error handling and supports optional remote
  discovery for configured push-key deployments. `--analysis-mode local` skips
  remote discovery configuration requests.
- Updates vulnerable dependencies and preserves scoped historical test-secret
  exceptions. No account, Snyk token, LLM call, or remote analysis is required
  for the default local analysis path.
- Adds the portable `open-agent-scan` skill for compatible AI coding tools:

  ```sh
  npx skills add rahulbsw/agent-scan --skill open-agent-scan
  ```

## Compatibility

This release moves scan analysis to risk-based responses using the upstream
`2026-07-10` API models. JSON consumers must validate their integration against
the new output before upgrading; legacy issue-code parsers may need changes.
Output fields remain experimental. The Python import package remains
`agent_scan`, and `agent-scan` remains a deprecated command alias.

Hook credentials remain externally provisioned. Uninstall removes local hook
configuration; administrators revoke the corresponding key in their provisioning
system. Local analysis can still execute configured MCP commands or contact MCP
endpoints during discovery, so review consent prompts and sandbox untrusted servers.

## Downloads

The release workflow builds macOS and Linux archives for x64 and ARM64, a Windows
x64 ZIP, and Python wheel/source distributions. It generates checksums, an SPDX
SBOM, and GitHub artifact attestations. Extract the platform archive and run
`open-agent-scan --help` from a terminal.

Python artifacts on GitHub Releases do not imply publication to PyPI. Installing
the AI-tool skill also does not install the scanner executable.
